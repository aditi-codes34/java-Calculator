------------------------------------------------------------------------
Title: Java calculator(basic)
------------------------------------------------------------------------

#About:
A simple GUI-based calculator developed in java.

#Features:
-> Addition
-> Subtraction
-> Multiplication
-> Division

- User-freindly graphical interface
- Uses ActionListener for button interactions 
- Uses MouseMotionListener for mouse interactions

#Technologies used:
- Java
- Java Swing
- ActionListener
- MouseMotionListener

#How to run:-
Open the project in Bluej, 
compile the Calculator class,
and run the program.
